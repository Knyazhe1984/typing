# Клавиатурный тренажёр

Бесплатный тренажёр слепой печати с открытым кодом. Без рекламы, без регистрации, работает офлайн.

- Раскладки: русская (ЙЦУКЕН), английская (QWERTY), цифры и спецсимволы
- Пошаговый курс: от постановки рук до полной клавиатуры
- Экранная клавиатура с раскраской по пальцам и схема рук
- Звёзды, достижения, серии дней, мини-игры (отключаются в настройках)
- Весь прогресс хранится только в вашем браузере

## Разработка

Нужен Node.js 24+.

```bash
npm install
npm run dev        # dev-сервер
npm test           # unit-тесты
npm run lint       # линтер
npm run build      # сборка в dist/
```

## Публикация

При пуше в `main` GitHub Actions собирает проект и публикует его на GitHub Pages.
Один раз включите в настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
